# 📚 单词闪卡 - 四六级背单词

一个完全运行在浏览器里的四六级单词闪卡工具，无需安装，打开即用。

## ✨ 功能

- 📚 内置四级 353 词 + 六级 310 词，全部带例句
- 🃏 点击卡片翻转，查看释义和例句
- 🔊 一键发音，支持键盘快捷键
- ✅ 标记认识/不认识，自动生成生词本
- 📊 学习打卡日历 + 每日目标进度条
- 🌙 夜间模式，晚上学习不刺眼
- 📱 手机电脑都能用
- 🔀 支持顺序/随机两种学习模式
- ⏰ 间隔提醒，按时复习
- 💾 学习进度自动保存

1. 点右上角绿色的 **Code** 按钮
2. 选 **Download ZIP**
3. 解压后双击 `index.html` 即可使用

## 🛠 技术栈

纯前端，无需后端：
- HTML + CSS + JavaScript
- 数据存储在浏览器 localStorage
- 使用 SpeechSynthesis API 实现发音
- 使用 Dictionary API 获取例句
